# 🛡️ DriverScanner Pro — сканер системы и драйверов

**`Платформа: Windows 10/11`** • **`Язык: Python 3`** • **`Версия: v1.0.0`**

> [!NOTE]
> **DriverScanner Pro** — это упрощенная и быстрая утилита для обнаружения установленных драйверов и программ на ПК без громоздких меню и лишней нагрузки на систему.

## ✨ Основные возможности
* 🔍 **Поиск драйверов:** быстро определяет список установленных в системе драйверов и их актуальные версии.
* 📦 **Сканирование ПО:** собирает полный перечень установленных на компьютере программ.
* ⚡ **Простота и скорость:** легкий интерфейс, запуск без долгой настройки.

## 🚀 Как установить и запустить
1. Перейдите в раздел **[Releases](https://github.com)** справа на странице и скачайте установщик `DriverScanner_Setup.exe`.
2. Запустите скачанный файл и следуйте инструкциям мастера установки.

> [!TIP]
> Для максимально полного доступа ко всем системным драйверам рекомендуется запускать программу **от имени администратора**.
