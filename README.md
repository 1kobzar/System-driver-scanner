# Сканер системы и драйверов

Упрощенная утилита на Python для быстрого поиска и проверки установленных драйверов и программ на ПК под управлением Windows.

## Основные возможности
* **Поиск драйверов:** быстро определяет список установленных в системе драйверов и их версии.
* **Сканирование ПО:** собирает актуальный перечень установленных на компьютере программ.
* **Простота и скорость:** легкий интерфейс без лишних настроек и высокой нагрузки на систему.

## Как установить и запустить
1. Перейдите в раздел **Releases** справа на странице и скачайте установщик `DriverScanner_Setup.exe`.
2. Запустите скачанный файл и следуйте инструкциям мастера установки.
